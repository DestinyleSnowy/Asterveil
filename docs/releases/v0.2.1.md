# Asterveil v0.2.1

本版本改进 Better Names 配色与姓名缓存，并修复题目页代码编辑器的选区和光标错位。

## 更新内容

- **姓名会话缓存**：官方、我的好友和 Better Names 计划按站点及登录账号复用缓存，刷新页面或打开新页面时不再重复请求和解密。过期数据先显示、再后台更新；手动刷新同步到同一账号的页面。退出登录、切换账号或明确失去访问权限后清空对应数据，旧页面和迟到请求无法恢复旧账号的缓存。缓存仅在浏览器会话内存中保存。
- **经典配色**：年级配色增加“经典”，保留同一届学生原有的颜色；例如原初2023级升为高2026级后仍使用黄色 `#FAAD14`。默认与自定义方案继续保留。
- **配色交互**：“恢复默认”仅在自定义模式下显示，选中底块平滑滑动，恢复按钮淡入展开、淡出收合，窄屏布局稳定；修复键盘切换配色后丢失焦点的问题，并尊重系统减少动态效果设置。
- **代码编辑器修复**：字体加载后自动更新字宽，修复框选、高亮和光标偏移；窗口缩放及编辑区尺寸变化时同步布局。保留原站代码、选区、撤销历史、语言、上传与提交流程，关闭界面微调后仍生效。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `Asterveil-0.2.1-chrome.zip` | 普通版，仅插件 |
| `Asterveil-Pro-0.2.1-chrome.zip` | Pro 版，仅插件，包含 PDF 功能 |
| `Asterveil-0.2.1-chrome-with-updater.zip` | 普通版，包含更新器 |
| `Asterveil-Pro-0.2.1-chrome-with-updater.zip` | Pro 版，包含更新器 |
| `SHA256SUMS.txt` | 安装包 SHA-256 校验值 |
| `update-manifest.json`、`update-manifest.sig` | 自动更新清单及 Ed25519 签名 |

已有用户可更新原加载目录，在扩展管理页重新加载，再刷新 7FA4 页面；先保存当前未提交的代码和作业草稿。设置、自定义配色与导入名单继续保留，更新后的首次访问会重新建立会话缓存。

含更新器的包加载其中的 `extension` 文件夹；更新器安装说明见仓库 [README](https://github.com/DestinyleSnowy/Asterveil#readme)。
