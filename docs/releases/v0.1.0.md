# Asterveil v0.1.0

面向 7FA4 的首个公开发布版本，提供普通版 Asterveil 和支持 PDF 的 Asterveil Pro。

## 主要功能

- 页面美化：主题配色、自定义颜色、浅色/深色/跟随系统，适配常用列表、题目、评测、模测、聊天等页面。
- 自定义首页：在设置中选择显示板块、调整顺序及左右栏，保留原有板块交互，支持恢复默认布局。
- 头像替换：几何方块、花瓣、小怪物、小团雀、猫咪、方脑袋、小芽灵共七种样式。每种都有多种配色，按用户固定生成；选定样式后立即应用并自动保存。预览展示不同配色，支持窄屏和深色模式。
- Markdown 编辑器：在线作答、公式预览、草稿、Markdown 保存、图片导出及提交、折叠已提交作业。Pro 版额外支持 PDF 导出、上传与提交。
- 题目与代码工具：复制题面源码、题号标题和提交代码，以及外站提交器。
- 两版同时启用时，普通版自动停用自身，优先使用 Pro，避免重复增强。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `Asterveil-0.1.0-chrome.zip` | 普通版，不含 PDF 功能，体积较小 |
| `Asterveil-Pro-0.1.0-chrome.zip` | Pro 版，包含 PDF 功能与所需资源 |
| `SHA256SUMS.txt` | 两个安装包的 SHA-256 校验值 |

1. 下载所需版本的 ZIP 并解压到固定目录。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，开启开发者模式。
3. 选择“加载已解压的扩展程序”，选中包含 `manifest.json` 的目录。
4. 刷新 7FA4 页面，在右下角星芒按钮中调整设置。

从本地开发版更新时，将新文件更新到原有加载目录，在扩展管理页点击“重新加载”，再刷新网站页面。切换安装实例前可先保存需要的 Markdown 草稿。

## 验证与适用范围

- 目标浏览器为 Chrome / Edge 120+；尚未验证 Firefox。
- 支持 `https://jx.7fa4.cn:8888/` 与 `https://in.7fa4.cn:8888/`，实际内网运行仍待验证。
- 发布流程执行格式与类型检查、26 项自动测试、两版构建，并核对安装包内容、版本、权限、资源和许可证。
- 外站提交解析依赖各站页面结构，发送后请核对目标站的提交记录。

更完整的功能说明见仓库 [README](https://github.com/DestinyleSnowy/Asterveil#readme)。
